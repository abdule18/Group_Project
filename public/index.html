FAQ

Is the backend already functional?

Yes — register/login, create tickets, comments, assignments, and status changes work out of the box once you import the SQL and set DB credentials.

Where do these buttons go?

They link to the PHP app: /register.php, /login.php, and /dashboard.php.

Can we deploy quickly?

Yes. Use Apache/Nginx with PHP 8+, set the document root to the public/ folder, and import the SQL. The landing page can sit at public/index.html or replace index.php links as needed.
